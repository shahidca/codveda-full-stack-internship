# Level 2 - Task 1: Frontend with a JavaScript Framework

## Overview

Built a modern React frontend using React, TypeScript,
Axios, and React Router.

The application communicates with the REST API created
during Level 1.

## Technologies

- React
- TypeScript
- Vite
- Axios
- React Router
- CSS
- REST API

## Features

- Component-based architecture
- Reusable React components
- User listing
- REST API integration
- Loading state
- Error handling
- Empty state
- Retry functionality
- Responsive design
- TypeScript interfaces
- Environment-based API URL
- Client-side routing
